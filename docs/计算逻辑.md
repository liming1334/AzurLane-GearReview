# 计算逻辑

本文说明本工具的全部伤害计算规则、参数含义与边界条件。

> 公式源自 [碧蓝航线 WIKI · 公式合集 · 伤害公式](https://wiki.biligame.com/blhx/%E5%85%AC%E5%BC%8F%E5%90%88%E9%9B%86#%E4%BC%A4%E5%AE%B3%E5%85%AC%E5%BC%8F)，
> 本工具在其基础上做了「77 秒窗口」与「逐级强化」两项工程化约定。

---

## 1. 基础伤害公式

WIKI 给出的完整形态：

```
最终伤害 = ((1 + 舰船面板属性/100 × 属性效率) × 武器伤害面板 × 武器修正比例
            × 武器效率 + 伤害波动)
           × 对甲效率 × 增伤类技能 × 敌方Debuff × 等级压制 × 暴击倍率
```

本工具对每一项的处理：

| 项 | 处理方式 |
|---|---|
| 舰船面板属性 | 界面参数（炮击/雷击/防空/航空），可叠加装备绿字 |
| 属性效率 | 界面参数，默认 100% |
| 武器伤害面板 | 取装备「伤害」字段（如 `16×6` 拆成 单发 16 / 弹数 6） |
| 武器修正比例 | 取「伤害补正」，随强化档位变化 |
| 武器效率 | 界面参数，默认 100% |
| 伤害波动 | 取 0（评分取期望下界，避免 +0/+1/+2 抖动） |
| 对甲效率 | 取「对甲比例」，轻/中/重各一套，**按百分数换算**（见下） |
| 增伤类技能 | 界面参数「增伤」 |
| 敌方 Debuff | 界面参数「debuff」 |
| 等级压制 | `1 + 等级差 × 0.02`，等级差为界面参数 |
| 暴击倍率 | 界面参数，默认 1（不计暴击） |

### 1.1 对甲比例是百分数

wiki 写 `对甲比例=75-110-75`，含义是 **75% / 110% / 75%**（`110%` 就是打中甲时
伤害 ×1.10，超过 100% 是正常的）。代码里 `parse_armor` 原样存百分数，
计算时才除以 100：

```python
armor_pct = item["armor"][ARMOR_KEYS.index(key)] / 100.0   # 舰炮
pct = (m.get("armor") or [0, 0, 0])[idx] / 100.0           # 舰载机挂载
```

界面的「基础数据」把它显示成 `80% / 115% / 75%`，避免和原始数值混淆。

## 2. 时间窗口：77 秒

评分定义为 **77 秒内能打出的总伤害**，超过 77 秒的部分直接丢弃。

### 2.1 舰炮 / 导弹 / 鱼雷 / 防空炮

```
装填系数 k = √(200 / (装填值 + 100))
开火间隔 T = k × 装填时间 + 开火动画
开火次数 n = floor(77 / T) + 1
评分      = 单轮伤害 × n
```

- `+1` 的来源：进入战斗时武器已装填完毕，t=0 打出第一轮
- 开火动画（前摇 + 后摇）按舰种取值：

| 舰种 | 动画 |
|---|---|
| 驱逐炮 | 0.26s |
| 轻巡炮 | 0.28s |
| 重巡炮 / 大口径重巡炮 / 絮库夫炮 | 0.30s |
| 战列炮（跨射） | 0s |
| 水面鱼雷 / 潜艇鱼雷 | 0.20s |
| 防空炮 | 0s |

### 2.2 舰载机

舰载机没有「开火」，只有「出击」，因此用 **标准射速** 作为出击间隔：

```
架次 = floor(77 / 出击间隔) + 1
评分 = 单架次挂载伤害 × 架次
```

出击间隔同样乘装填系数 `k`（与舰炮一致），动画为 0。

## 3. 舰载机拆解

一架飞机的伤害来自三类挂载，WIKI 页面写法形如：

```
机枪=2 x 7.92mm MG17机枪T3,2 x MG FF 20mm机炮T3
炸弹=4 x 100lb 炸弹T3
鱼雷=2 x 机载鱼雷-铁血T1
```

### 3.1 数值来源

挂载只是「名字 + 数量」，真实数值在三张数据库表里：

- `模板:舰载机图鉴/数据库/机枪`
- `模板:舰载机图鉴/数据库/炸弹`
- `模板:舰载机图鉴/数据库/鱼雷`

每行格式：

```
2 x 20mm机炮T3=33,,,45,,,60,65,,,80,83,,94;169,,,158,,,149,146,,,135;36;80
                └────── 伤害 0~13 级 ──────┘ └──── 射速 ────┘ 射程 射角
```

伤害列表共 14 个位置，分别对应强化 **+0 ~ +13**，空位表示该档无数据。
注意数据库的键 **包含「数量 x」前缀**（`2 x` 和 `4 x` 的单发伤害可能不同），
所以匹配时先用整串，失败再退回裸名。

### 3.2 对空 / 对甲的分工

| 挂载 | 计入 | 公式 |
|---|---|---|
| 机枪 | 对空评分 | `Σ(单发 × 数量) × (1 + 航空/100 × 属性效率)` |
| 炸弹 / 鱼雷 / 火箭弹 | 对甲评分 | `Σ(单发 × 数量 × 对甲%) × (1 + 航空/100 × 属性效率 × 武器属性效率)` |

武器属性效率：

| 类型 | 效率 |
|---|---|
| 普通航空炸弹 | 80% |
| 火箭弹（HVAR / RP-3 / RS-82 / S-21 / Wfr.Gr / TinyTim） | 100% |
| 航空鱼雷 | 100% |
| 机枪 | 100% |

> TinyTim 属于火箭弹，按 100% 处理。

### 3.3 一个例子

`AD-1 天袭者T0`（强化 +10）：

```
炸弹 1 × 1000lb 炸弹T0   单发 440，对甲 85/95/110
炸弹 8 × HVART0          单发 104，对甲 140/110/50（火箭弹，效率 100%）
航空 65（不计装备加成时面板 100 + 65）
```

对轻甲单架次：

```
1000lb：440 × 1 × 0.85 × (1 + 165/100 × 0.8) = 1,007
HVAR  ：104 × 8 × 1.40 × (1 + 165/100 × 1.0) = 3,086
合计 ≈ 4,093（含增伤等乘区后为 4,525.7）
```

77 秒内出击 6 架次 → 评分 27,154。

## 4. 强化档位

界面可选 **无强化 / +3 / +6 / +7 / +10 / +11 / +13**。

规则分两步：

**第一步：按装备自身上限截断。**

每件装备的 `max_level` 由页面里出现的所有 `强化+Nxxx` 字段取最大值
（伤害、射速、伤害补正、耐久……任一即可），页面一个都没有时按稀有度兜底
（白 3 / 蓝 6 / 紫 10 / 金 13 / 彩 13）。

**白色与蓝色还要再按稀有度上限截断一次**，因为「页面字段最大值」并不可靠：

| 现象 | 例 | 处理 |
|---|---|---|
| 空的占位字段 | 蓝色页留了 `强化+13伤害补正 = ''` | 只按键名取最大值会虚高到 13 |
| 补正多一档 | 蓝色 `强化+7伤害补正 = 114`，但伤害与射速只到 +6 | 补正天生比伤害/射速多一档，不代表能到 +7 |
| 占位文本 | 白色 `强化+7伤害 = 待补充` | 会被当成一档 |

- 白色：`min(页面最大档, 3)`
- 蓝色：`min(页面最大档, 6)`
- **紫色及以上暂不截断**，仍按页面原值（口径待定）

> 这一步对舰载机是必需的：武器库里存了 +0~+13 的全部档位，
> 但白色飞机只能强化到 +3。不截断就会拿 +13 的数值 ——
> 这正是「F4F野猫T1 显示 68 而非 33」的原因。

> 实现见 `core.effective_max_level(rarity, observed)`，返回该装备实际上限。

**第一步补充：伤害补正缺失时按模板兜底。**

wiki 的装备模板对空的 `强化+N伤害补正` 有 `#expr` 兜底（舰炮 / 鱼雷 / 导弹 / 防空炮一致）：

| 稀有度 | 涨补正的档位 | 兜底公式 |
|---|---|---|
| 蓝色 | +7 | `round(伤害补正 × 1.04)` |
| 紫色 | +11 | `round(伤害补正 × 1.04)` |
| 金色 / 彩色 | +13 | `round(伤害补正 × 1.18)` |
| 白色 | 无 | — |

页面上写了就用页面上的值（可能出现在任意档位），没写才套兜底。

> 例：`双联装203mmSKC主炮改T0` 页面上 `强化+13伤害补正=` 是**空**的，
> 但 wiki 渲染出来是 130%（110 × 1.18）。只读页面参数会停在 110%，
> 该炮的评分因此少算约 18%。全库共 24 件（18 金 / 3 彩 / 3 紫）踩到这个坑。
>
> 实现见 `core.build_correction_levels(params, category, base, rarity)`。
> 舰载机的补正不参与评分，模板也没有这套兜底，所以不补。

**第二步：取「不高于目标档位」的最高已有档。**

- 选 +13，装备上限 +10 → 按 +10 计，详情红字提示
- 伤害、射速、伤害补正 **三者各自独立取档**
- 例：某炮 +10 有伤害与射速，+13 只写了伤害补正 → 选 +13 时
  伤害用 +10 值、补正用 +13 值

数据结构（`item["levels"]`）：

```python
{
  "damage":     {0: (7.0, 6.0), 10: (17.0, 6.0)},   # 0 → (单发, 弹数)
  "reload":     {0: 1.94, 10: 1.65},
  "correction": {0: 100, 10: 125, 13: 148},
}
item["max_level"] = 10      # 该装备自身能到的最高档
```

## 5. 参数表

| 参数 | 默认 | 作用 |
|---|---|---|
| 炮击 / 雷击 / 防空 / 航空 | 100 | 对应类别的面板属性 |
| 属性效率 | 100% | 面板转伤害的效率 |
| 装填值 | 100 | 决定装填系数 k |
| 增伤 | 0% | 弹药强化类乘区 |
| 暴击倍率 | 1.0 | 1 = 不计暴击 |
| 武器效率 | 100% | 武器槽效率 |
| 强化等级 | +13 | 0/3/6/7/10/11/13 |
| 计入开火动画 | 开 | 关掉只算装填时间 |
| 计入装备属性 | 开 | 装备绿字叠加进面板 |

等级压制与 debuff 也可以通过参数文件微调（`data/settings.json`）。

## 6. 已知边界

- **伤害波动** 取 0，因此评分是最小值（下界），实际战斗会在 +0/+1/+2 间浮动
- **暴击** 默认不计，需要时把「暴击倍率」改成 1.5
- **燃烧 / 进水** 等持续伤害不计入
- **命中率、闪避、散布** 不计入，评分是「全中」的理论值
- **防空炮** 只算对空，没有对甲维度
- **舰载机** 的机枪只算单发命中伤害，不乘射速；机枪射速仅作展示
- 设备与特殊兵装已在数据层剔除，不参与评分
