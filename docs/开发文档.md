# 开发文档

## 1. 架构总览

```
┌──────────────────────────── main.py ────────────────────────────┐
│  入口：解析命令行（--selftest 联网自检），否则启动界面           │
└───────────────────────────────┬─────────────────────────────────┘
                                │
        ┌───────────────────────┴───────────────────────┐
        │                                               │
┌───────▼────────┐                            ┌─────────▼─────────┐
│   app/core.py  │  纯逻辑，无 UI 依赖        │    app/ui.py      │
│  网络 / 解析   │◀───────────────────────────│  Tkinter 界面     │
│  评分 / 资源   │   dict / list 结构化数据    │  主题 / 背景 / 卡片│
└───────┬────────┘                            └───────────────────┘
        │
        ▼
  data/equipment.json     装备主数据（674 件）
  data/plane_weapons.json 舰载机武器库
  assets/icons/           图标 PNG + icons.json
```

**分层原则**：`core.py` 不 import tkinter，可以在命令行、脚本、测试里复用；
`ui.py` 只做呈现与交互，所有计算都调 `core`。

## 2. 数据模型

### 2.1 装备条目 `item`

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | str | 完整名，如 `双联装138.6mm主炮Mle1934T0` |
| `base_name` / `tier` | str | 去掉 `T0~T9` 的系列名 / 型号 |
| `category` | str | 舰炮 / 导弹 / 鱼雷 / 防空炮 / 舰载机 |
| `type` | str | 子类型：驱逐炮、战列炮、水面鱼雷…… |
| `rarity` / `faction` | str | 稀有度 / 阵营 |
| `armor` | [float×3] | 对甲比例（轻/中/重，百分数） |
| `levels.damage` | `{lv: (单发, 弹数)}` | 逐级伤害 |
| `levels.reload` | `{lv: 秒}` | 逐级装填 |
| `levels.correction` | `{lv: %}` | 逐级伤害补正 |
| `max_level` | int | 该装备自身的强化上限（评分时先按它截断） |
| `stat_bonus` | `{属性: 值}` | 装备绿字 |
| `mounts` | `{mg/bomb/torp: [...]}` | 仅舰载机：解析后的挂载 |
| `score` | `{对空/轻甲/中甲/重甲: {...}}` | 评分结果（运行时写入） |
| `payload` | float | 仅舰载机：单架次挂载总伤害 |
| `raw` | `{str: str}` | 模板原始参数，详情面板直接展示 |

### 2.2 评分条目

通用字段：

```python
{
  "value": 19633.0,      # 77 秒累计伤害（排序键）
  "dps":   254.9,        # 等效秒伤
  "kind":  "gun" | "aa" | "plane" | "plane_aa",
  "stat":  145.0,        # 参与计算的属性
  "bonus": 45.0,         # 装备加成
  "attr":  2.45,         # 属性系数
}
```

舰炮额外：`volley`（单轮含对甲）、`volley_raw`、`cycle`、`shots`、
`correction`、`armor_pct`、`reload`、`count`、`damage`、`level_used`。

舰载机额外：`per_sortie`、`sorties`、`cycle`、`mounts`（明细行）。

## 3. 关键函数

### core.py

| 函数 | 职责 |
|---|---|
| `api_get(params)` | POST 调用 MediaWiki API，4 次退避重试 |

| `fetch_texts(titles)` | 50 页/批取 wikitext，失败降级重试 |

| `score_gun(...)` | 舰炮/导弹/鱼雷/防空炮评分 |
| `score_plane(...)` | 舰载机评分（对空 + 三甲） |
| `score_all(items, params)` | 批量评分并写回 `item["score"]` |
| `simulate(item, params, secs)` | 任意时长输出测试 |
| `pick_level / used_level` | 强化档位的「就低回退」逻辑 |
| `load_data()` | 读缓存，失败回退内置快照 |

### ui.py

| 方法 | 职责 |
|---|---|

## 4. 界面实现要点

### 4.1 主题系统

所有颜色集中在 `THEMES`（`day` / `night`），key 语义化：`window`、`card`、
`line`、`text`、`muted`、`accent`、`gold`……

静态控件在创建时交给 `_label / _frame / _button`，它们把
`(widget, {选项: token})` 记进 `self._themed`。切换主题时统一
`widget.configure(**{k: theme[v]})`；ttk 控件走 `_apply_ttk_style()`。

> **坑**：clam 主题自带 `TCombobox` 的 `readonly` 状态映射（浅灰），
> 必须显式 `style.map(...)` 覆盖，否则只读下拉框永远是白底。

详情面板每次重建，天然跟随主题，无需额外登记。

### 4.2 背景图

Tk 没有真正的透明控件，所以采用「底图 + 留白」策略：

1. 根窗口最底层放一个 `Label`（`place` 铺满），显示按窗口尺寸 cover 裁切、
   高斯模糊、并按主题叠色的图片；
2. 筛选/参数收进一张带边距的卡片，表格与详情之间留 sash 间隙，
   这些缝隙会露出底图；
3. 详情卡片不用内嵌 Frame，而是直接 `create_window` 挂到 Canvas 上，
   Canvas 上再画一块「与窗口同位」的底图裁剪 —— 卡片之间就能透出壁纸。

背景文件复制到 `data/background.<ext>`，路径记在 `data/background.json`。

### 4.3 毛玻璃按钮

Tk 没有透明度，按钮的「毛玻璃」是预渲染图：

1. 取按钮所在位置的底图（没有壁纸时用容器色）；
2. 重模糊（半径 10px）后按 40%~62% 混入容器色；
3. 套圆角矩形蒙版（半径 8px），再叠 1px 高光描边；
4. `button.configure(image=..., compound="center")`，文字浮在图上。

窗口缩放、切换主题、更换背景后都会重新生成（`_apply_glass_all`）。

### 4.4 表格

- `show="tree headings"`：用 `#0` 列放图标 + 名称，其余列放数据
- 行标签按「稀有度|奇偶」组合注册，同时实现稀有度着色与斑马纹
- 点击表头 `sort_by()`，同一列再次点击切换升降序

## 5. 构建与发布

### 5.1 为什么默认 onedir

PyInstaller 单文件模式启动时要把运行库解压到 `%TEMP%`，
在受限环境（沙箱、临时目录不可写/不存在）会直接报
`could not create temporary directory!` 且无窗口程序看不到报错。

`--onedir` 把依赖放在 `_internal/`，**运行时不需要临时目录**，
启动也更快。代价是必须整个文件夹一起移动。

### 5.2 命令

图标由 `assets/app.ico` 提供（由 `assets/app_source.jpg` 居中裁切生成，
16/24/32/48/64/128/256 多尺寸）。

```powershell
# 免解压版（默认）
python -m PyInstaller --onedir --windowed --name 碧蓝装备排行 `
  --icon assets/app.ico `
  --add-data "data/equipment.json;data" `
  --add-data "data/plane_weapons.json;data" `
  --add-data "assets/app.ico;assets" `
  --add-data "assets/icons;assets/icons" main.py
```

打包依赖 PyInstaller / Pillow，仓库 `vendor/` 目录下是本地安装副本
（本机 pip 曾受沙箱限制，改为直接解压 wheel）。

### 5.3 自检

```bash
python main.py --selftest     # 退出码 0 = 联网抓取链路正常
python tools/smoke_ui.py 舰炮 out.png [--night] [--bg=图片]
```

## 6. 扩展指南

### 新增装备模板

1. `core.TEMPLATES` 加一行 `"模板名": "大类"`；
2. 若字段名不同，在 `parse_page` 里做兜底（参考导弹的 `导弹先锋对甲比例`）；
3. 若需要参与评分，在 `score_all` 的分支里加类别，并实现对应 `score_*`。

### 新增主题

复制 `THEMES["day"]` 改色，补齐所有 token，然后在顶栏按钮里加一个切换项。
`_apply_theme` 会自动处理已注册控件。

### 新增评分维度

在 `score_gun` / `score_plane` 里多返回一个 key（如 `"护盾"`），
`SCORE_KEYS` 与 `COLUMNS` 相应增加即可，详情卡片会自动渲染数字牌。

## 7. 已知限制

- 舰载机机枪未乘射速，只算单发命中伤害（射速仅展示）
- 不模拟散布、命中、防空减伤、燃烧/进水
- 设备与特殊兵装已按要求剔除
- WIKI 若调整模板字段名，需要同步修改 `parse_page`
