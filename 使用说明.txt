碧蓝航线 · 装备性能排行工具
================================

按 WIKI 装备数据计算「77 秒内累计伤害」并排名的离线小工具。
数据（674 件装备 + 图标）已经打包在程序里，不需要联网、不需要装 Python。

一、怎么运行
--------------------------------
【单文件版】从 GitHub Releases 下载单文件版 exe（当前文件名 v1.0.0.exe）
下载地址：https://github.com/liming1334/AzurLane-GearReview/releases

· 就一个文件，双击直接用，方便发给别人
· 首次启动会先解压到系统临时目录，约 3~5 秒
· 因为体积大且会被解压，个别杀毒软件可能误报，加白名单即可

如果系统禁止在临时目录运行程序，可以改用源码运行：
    python main.py


二、基本用法
--------------------------------
1. 左侧表格：点表头可排序，比如点「评分·轻甲」按对轻甲伤害排
2. 上方筛选：按分类 / 类型 / 稀有度 / 阵营 / 搜索词过滤
3. 参数栏：炮击、雷击、防空、航空、装填值、强化档位……改完自动重算
4. 右侧详情：点任意一件装备，看评分拆解、基础数据、舰载挂载、技能、完整属性
5. 右上角「☾ 夜间 / ☀ 白天」：切换配色，会记住选择
6. 「输出测试」：算任意秒数下的总输出
7. 「导出 CSV」：把当前表格存成表格文件


三、说明
--------------------------------
· 评分是理论伤害：只算伤害公式，不含命中率、散布、索敌等因素，
  实际表现还要看索敌范围、索敌角度、弹药射程、散布角度。
· 强化档位按装备自身能到的上限自动截断（比如白色飞机只能 +3）。
· 数据更新：程序内置了抓取结果，日常使用无需联网；
  「更新数据」按钮会联网重抓 WIKI，网络不好时可以忽略。
· 设置与缓存存放在 exe 同级的 data 文件夹；
  如果放在 Program Files 这类没有写权限的位置，会自动改存到
  %LOCALAPPDATA%\AzurLaneEquipRank。


四、常见问题
--------------------------------
Q: 双击没反应 / 弹窗报错？
A: 先确认文件没有被杀毒软件隔离；单文件版首次启动需要等 3~5 秒解压。

Q: 界面图标是羽毛 / 显示不全？
A: 确认使用的是最新的单文件版；图标已内置，不需要额外文件。

Q: 排行和游戏里体感不一样？
A: 这是纯公式计算，没有考虑命中、散布、弹道和操作手法，适合做横向比较。
